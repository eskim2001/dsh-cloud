# dshcloud Design System & Brand Identity

> 本文件记录了 dshcloud 区别于其他一切常规 SaaS 产品的核心视觉世界观。
> **请所有未来的 AI 辅助开发者在修改 UI 时，严格遵循以下美学约束。**

## 一、核心品牌隐喻：黑曜石沙箱与深海微光

dshcloud 不是一个简单的前端套壳，它是一个活着的、带有多租户隔离生命周期的云端容器托管平台。基于这个产品属性，它的视觉设计必须传达三种感觉：**不可信沙箱的物理硬核感、DeepSeek 宇宙的深渊感、以及底层容器运转时的呼吸感。**

### 为什么不用 DeepSeek 官方蓝？
如果在云平台上使用 DeepSeek 本体的高亮蓝色，会产生两个灾难：
1. **品牌撞车**：模糊了“大模型 API 服务”与“Agent 隔离运行时托管平台（Harness）”的区别。
2. **沦为平庸**：瞬间退化成阿里云、腾讯云、AWS 那种千篇一律的、枯燥的“企业级管理台模板蓝”。

### 为什么不用纯 Terminal 黑白？
纯粹的黑白属于 `deepseek-harness` 这种在本地跑的 CLI 脚本。但一旦上了云，成为带有控制面、资源监控、随时在后台持续运行的云平台，如果只有纯黑白就会显得像一个未完成的终端工具箱，**缺乏作为 SaaS 平台 24 小时不断运转的“生命力”。**

### 最终解：深海绿 (Deep Sea Green) + 黑曜石 (Obsidian)
- **黑曜石（#050505）**：继承自 Harness 的终端硬核本色，代表安全的隔离舱与数据卷。
- **深海绿（#087f71）**：千米深渊下真正折射出的水色（深海不蓝，深海是墨绿）。它像一抹属于云端容器沙箱的生物冷光，从死寂的黑曜石底色里孕育而出，构成了 dshcloud 极其自洽、独立的科技品牌语言。

## 二、视觉元素规范 (Visual Craft)

**最高纲领**：Zero glassmorphism (零泛滥毛玻璃), Zero pill chips (零廉价胶囊标签), High-restraint developer craft (高克制的开发者工艺)。

### 1. 颜色标尺 (Color Palette)
- **Background (Brand Panel)**: `#050505` (纯粹的黑曜石，绝对的暗色)
- **Brand Accent**: `#087f71` (深海冷翠绿，核心 CTA 与体积光)
- **Brand Accent (Hover Light)**: `#055950` (下压时的暗翡翠色)
- **Brand Accent (Hover Dark)**: `#0a9b8a` (高亮时的荧光感绿色)
- **Text (Primary)**: `#ffffff` (用于黑曜石背景上的主标题与鲸鱼)
- **Text (Muted)**: `#888888` (柔和银灰色，用于副标题 `Gateway...` 与 logo 的 `cloud.`，**严禁在暗背景上使用深绿色字，确保对比度**)

### 2. 四大核心构造纹理 (Structural Textures)
在登录页或任何“全局品牌展示区”，必须通过这四个层次建立空间感：
1. **暗色拓扑网格 (Blueprint Grid)**
   - 尺寸：`80px` / `56px` 的背景工程网格。
   - 颜色：夜间模式为极微弱的深海绿 (`#087f711a`)，日常模式为带有一点质感的灰绿 (`rgba(136,136,136, 0.5)` + `mask-image` 径向淡出)。
   - 隐喻：隔离沙箱的绝对坐标空间与工程严谨感。
2. **电影级环境呼吸光 (Cinematic Breathing Glow)**
   - 实现：大面积的超柔和径向渐变 (如 `ellipse at 50% 0%`) + 极度夸张的模糊 (`filter: blur(60px)`) + 12-15 秒周期的缓慢缩放平移 (`cinematic-breathe`)。
   - 隐喻：深水下透出的微光，以及庞大的底层容器集群在呼吸运转。
3. **极度克制的不透明卡片 (Crisp Opaque Restraint)**
   - 规则：**严禁滥用大面积的毛玻璃（Frosted Glass）和低透明度背景**。过度使用会带来廉价的“AI生成感”和“模板味”。
   - 实现：在日常界面中，只使用坚实、不透明的底色（`bg-card`），仅靠极其克制的投影 (`shadow-sm`) 和微动效来区分层级，让背后的环境呼吸光作为背景氛围而非干扰。
4. **发丝边界线 (Hairline Border)**
   - 实现：`1px solid var(--border)`。
   - 隐喻：用来干脆利落切割界面，决不使用臃肿的全局大阴影。

### 3. 组件级交互 (Interaction)
- **CTA 按钮 (如登录按钮)**：本体必须是明确的深海绿（`#087f71`），拒绝黑白无彩色的“平时没性格，悬停才变色”的生硬交互。操作反馈需依靠同色系的明暗调整。
- **动效 (Motion)**：必须是极度平滑的（如贝塞尔曲线），巨鲸出水的 SVG 动画分离了水波、远云和主体三个图层，绝不允许用简单的 CSS Hover Scale 替代。所有关键动效必须支持 `prefers-reduced-motion` 响应。

## 三、移动端降级原则 (Mobile Degradation)

在手机端响应式处理时，首要原则是：**不丢失品牌面板的独立性。**
- 不能因为屏幕小，就把黑曜石品牌区设为透明、融合进白色表单里。
- 必须采用**两段式全景布局 (Edge-to-Edge)**：上方直接铺满 100% 宽度的黑曜石质感区块（保留呼吸光与网格），下方无缝衔接登录表单。
- 不得存在无意义的边距（Padding）导致黑曜石变成一个奇怪的“悬空黑块”。
